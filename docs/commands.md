# Commands

`/powers` and its alias `/skills`. Subcommands other than `info` and `build` for yourself need
permission level 2.

| Command | Effect |
| --- | --- |
| `/powers` or `/powers info [player]` | Origin, level, RPG level, points, abilities and keystones |
| `/powers build [player]` | Prints a build code; click it to copy |
| `/powers points add\|remove\|set <players> <n>` | Changes bonus skill points (`set` sets the available total) |
| `/powers level add\|set <players> <n>` | Changes the Power level |
| `/powers xp add <players> <n>` | Grants Power XP |
| `/powers reset <players>` | Refunds the whole tree for free |
| `/powers origin <players> <school>` | Resets and grants an origin |
| `/powers grant <players> <node>` | Allocates the path to a node and adds the points it costs |
| `/powers cooldowns <players>` | Clears cooldowns and refills Essence |
| `/powers cast <players> <ability>` | Casts any ability, ignoring unlocks, cost and cooldown (testing and map making) |
| `/powers reload` | Reloads config and tree and resyncs every player |
